# moleculer-template-module
:mortar_board: Module template for [moleculer-cli](https://github.com/moleculerjs/moleculer-cli)

## Usage

```bash
moleculer init module my-moleculer-module
```

## Features

- Moleculer 0.15 compatible
- Node.js 22+ required
- ESLint 9 with flat config
- Jest 30 for testing
- GitHub Actions CI (Node 22 & 24)
- Prettier code formatting
- VS Code debug configuration
- Param validation example
